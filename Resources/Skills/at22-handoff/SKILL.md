# AT22 の記憶DB に書く（節目と引き継ぎ）

AT22 は記憶DB を一覧に出し、清書して `PROJECT.md` にまとめる。書くのは**あなた本人**（後から要約すると意図が落ちる）。

## 置き場

```bash
bash ~/.claude/skills/at22-handoff/note.sh <セッションID>
```

出力の1行目がこのセッションのノート（`…/memory/sessions/each/<セッションID>.md`）、2行目がほかのセッションと共有する
`SHARED.md`。記憶DB は worktree ではなく**リポジトリ本体**のものを使う（`note.sh` が本体を引く）。
AT22 が置き場を書いて渡してきた時は、そちらに従う。

## 節目のノート

無ければ次の頭を付けて作り、節目ごとに短い節を足す:

```
---
name: 一言の題
description: このセッションで何をしているか1行
type: progress
originSessionId: <セッションID>
---
```

本文は「決めたこと／分かったこと／残り」を数行ずつ。終えたら末尾に ```` ```state ```` の囲みで `stage: done`。
ほかのセッションにも効く事実（約束・前提・落とし穴）は `SHARED.md` にも1行足す。`PROJECT.md` は清書の時にだけ書き換える。

## 引き継ぎ（文脈が溢れそうな時）

同じノートに節を足す。中身は「決めたこと」「分かったこと」「残り（手順の番号つき）」「次の一手」。読むべきファイルはパスで書く。
末尾に ```` ```state ```` の囲みで `stage: handoff` と `next: 次の一手を1行`。書き終えたらそれ以上は進めずに返事を終える
（AT22 がこのノートから新しい会話を起こす）。
