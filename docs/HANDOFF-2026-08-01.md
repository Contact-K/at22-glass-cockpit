## いちばん大事な前提

**このセッションで書いたコードは1行もコンパイルされていない。**
Cowork のクラウド環境は Linux で CoreGraphics も SwiftUI も無く、デバイス側のシェルも Linux VM なので、
`swift build` も `p0-selfcheck` も回せなかった。

代わりに、独立レビュー（別コンテキストの Sonnet）を3周かけて「ビルドが落ちる箇所」を潰した。
実際に3件見つかって直している（後述）。それでも**最初にやることはビルドと p0 検査**。

```
swiftc -parse-as-library Sources/AT22/{Transcript,Cockpit,CockpitLayout,Structure,Memory,Gate,Launcher,Snowman,Category}.swift \
  p0-selfcheck.swift -o /tmp/p0check && /tmp/p0check     # → p0: ok
swift build
```

`Category.swift` がコンパイル行に増えている。`TaskList.swift` と `MessageWindow.swift` は
SwiftUI 依存なので**入れない**（この検査はターゲット外・SwiftUI 非依存のまま）。

## レビューで実際に潰した欠陥（記録）

ビルドできない状態で書いたので、ここは残しておく価値がある。

1. **`ctx.clip(to:)` が呼び出し元を汚染していた**（最重）。`drawCell` は `inout GraphicsContext` を
   受け取るので、カテゴリ帯のために掛けたクリップが**そのあと描く全部**（同じセルのティック・名前、
   次のセル、他のカード、チップ、凡例）に残り、画面が壊れる。ローカルに複製してから掛けるよう修正
2. **`ctx.fill(band, ...)` に `CGRect` を渡していた**。`fill` の第1引数は `Path` だけ。`Path(band)` に修正
3. **`p0-selfcheck.swift` の `CellBox` 直接生成に `category` が無く引数不足**。
   `CellBox(` はリポジトリ全体で3箇所（`CockpitLayout` に2、`p0-selfcheck` に1）。検査側を忘れていた
4. `FileCategory` の語境界が `FooTests.swift` を拾えなかった（`Test` の直後が `s` で終端境界を満たさない）。
   語末で `s` を1文字読み飛ばす規則を足して、`XxxTests` `XxxSpecs` `XxxTestCase` を拾えるようにした。
   `testament.txt` `latest.swift` `contest.md` `spectrum.md` は拾わないまま
5. `.gitignore` のような先頭ドットのファイルが `NSString.pathExtension` の挙動に依存していた。
   版によって `""` を返しうるので、`classify` の側で先に確定させる形にした
