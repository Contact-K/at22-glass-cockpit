## SUMI_ の規律（readme から v10 に効く所だけ）

- 色は **青 `#1212EE` × 白** の2色。深紺 `#08085C` は第3の面。差し色は **ピンク `#FF3DCC` 1色だけ**、面積は常に小さく（節番号 `01 //`、門の点滅、決定のドットの飛行中、遷移の波紋の先頭）
- 角丸は**すべて 0**。影は**なし**。区切りは 1px 罫線と明度差。強調は実線、従属は破線
- 英語が主・日本語が従。見出しは Fraunces、和文は DotGothic16 で下に従属。**青柳衡山T は節番号の横の小さな和文ラベル（14px）だけ**
- ラベル・数値は Departure Mono の大文字＋字送り .14em。`// OVERVIEW` `#1` `[×]` `▸`。絵文字なし
- 動きは 100–200ms、機械的（`steps(3)` 等のコマ送り）。バウンス・ぼかし・透過なし（モーダルの幕 `rgba(8,8,92,.8)` だけ）
- ボタンは直角の塊。押下は `translate(1px,1px)`
- 鶴 = メニューボタン = 読み込み表示。左下の1羽だけ。処理中は四角に畳まれて InkLoader になる
- メニュー: 白い斜線（18°）が引かれる → 線から離れる順にドットが育って青い面になる → 項目が線に沿って並ぶ。選択だけ白い板（右端が尖る）＋刃。下層は面の色が深くなり、白帯が横切る間に差し替え
