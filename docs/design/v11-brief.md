# v11 モックの注文書 — AT22 を Orca 風の IDE に

claude.ai/design に渡す用。**見た目は決めていない。** 画面ごとに「何を出すか・何を押せるか」だけを書く。
土台は Sumi v10（`docs/design/sumi-v10/`）。語彙（青×白・差し色ピンク・角丸0・鶴・斜めの板・`NN // LABEL`）はそのまま使う。

決まっていること:
- エージェントを動かすのは**構造化チャット**（今の 01 TALK）。端末は**脱出口**
- エディタは**人が手で介入する時のパーキングブレーキ**（1ファイルを開いて直して保存。IDE の主役ではない）
- 見渡しは**タイルで全部見る**

## 0. 階層と行き来

```
管制塔（全 worktree のタイル）
  └ タイルを選ぶ → その worktree の画面（v10 の 01 TALK / 02 STRUCTURE / 03 SPARRING ＋ 新しい面）
```

決めてほしい:
- 管制塔はどこに住むか（起動直後の画面／メニューの 00／専用のキー）。戻る鍵は何か
- worktree の中の新しい面（REVIEW / TERMINAL / FILES）は、タブ 04〜 にするか、下や右から引き出す板にするか
- v10 の右の列（04 ACTIONS / 05 PLAN）と墨流しは、新しい面でも残すか

## 1. 管制塔（タイル）

プロジェクトごとに束ねた worktree のタイル。1枚に出すもの:

| 項目 | 例 | 備考 |
|---|---|---|
| 名前とブランチ | `legend-fix` · `at22/legend-fix` | 本体の worktree は印を変える |
| エージェントの行（複数） | `Claude opus-5.5` `Grok` | 1 worktree に何体でも |
| 状態 | 作業中 / **あなた待ち** / 完了 / 失敗 / 待機 | あなた待ち＝承認・門・入力待ち。いちばん目立たせる |
| 未読 | 見ていない間に終わった・訊いてきた | 太字や印 |
| 最新の発言 1 行 | 「凡例を作り直しました…」 | |
| 差分の量 | `+42 −7` · 3 files | 基点から |
| PR と CI | `PR #42` ✓ / ✗ | あれば |
| 競走の束 | 同じ指示で走る `-claude` `-grok` を1組に | 勝者を「採る」 |
| 作成中・失敗 | 進み具合、失敗したら再試行と閉じる | |

押せるもの: タイル（入る）／＋（新規）／タイルのメニュー（Terminal で開く・消す・採る・登録を外す）。
並べ方: あなた待ち → 作業中 → 完了（未読）→ 待機。数が多い時（20 枚超）の見せ方も。

## 2. 作る・消す・採る（板）

- **新規ワークスペース**: リポジトリ／どこから分岐（既定は今のブランチ）／名前（＝ブランチ名）／エージェント（複数選ぶと競走）とモデル／最初の指示／承認の段（Lv.2〜5）
- **削除の確認**: 未コミットのファイル一覧を見せる。「変更ごと消す」は確認後だけ。マージされていない枝は残る、と伝える
- **採る**: 競走の勝者を残し、負けを（未コミットの数を見せてから）消す

## 3. 移動（⌘J）

全 worktree のエージェントを、あなた待ち → 作業中 → 完了 → 待機 の順に並べたパレット。⌘1〜6 で直に飛ぶ。
v10 のメニュー（斜線＋巨大英字）と同じ世界にするか、別の小さな板にするか。

## 4. REVIEW

- 左: 変わったファイルの一覧（`+12 −3`、追跡外の新規も）。上に基点（`基点 a1b2c3d4`）
- 右: 差分（行番号・追加/削除の行）。**行にコメントを付ける** → 溜めて「エージェントに送る」で1通に
- **ハンクごとにステージ／外す**
- コミット（文を書く欄）／push／PR を作る。どれも押した時だけ
- コミットの履歴（基点から）と、PR・CI の状態
- ファイル名や行から **エディタで開く**

## 5. TERMINAL

- worktree ごとの端末。複数本（タブか並び）。中身は普通のシェル（`git status`、テスト、`claude --resume`）
- 置き場: 下から引き出す／タブ／板 のどれか。**チャットを見ながら端末を打てる**配置が要るか
- 配色は青×白でいくか、端末だけ深紺地（`#08085C`）にするか。書体は Departure Mono

## 6. FILES とエディタ

- ツリー（`.gitignore` を尊重）、⌘P のクイックオープン、プロジェクト内検索（結果は ファイル:行）
- エディタ: 1ファイル。行番号、未保存の印、⌘S、⌘F。**外で書き換えられていたら上書きせず、読み直すか上書きかを訊く**（03 SPARRING の編集欄と同じ）
- シンタックスハイライト・複数タブ・自動保存は無い
- 入口: ツリー、検索結果、REVIEW の行、04 ACTIONS の行、`// FILE` の板

## 7. 承認カード

いまは門（`Wake W3?`）と道具の承認（`Run Bash?`）を同じカードで仮置きしている。
- 道具の承認は**道具の入力（コマンドや差分）を読める**形に。Rewrite は入力（JSON）の書き換え
- ACP（Grok）は書き換えができないので Rewrite が無い
- 複数溜まった時（他 N 件）と、別の worktree で止まっている時の見せ方（管制塔のタイルと上帯の札）

## 参考: いまモデルが持っているデータ

`Cockpit.workspaceTree()` → プロジェクト / ワークスペース（名前・ブランチ・本体か・作成中）/ エージェントの行（題・相手・状態・未読）。
`Cockpit.review(path)` → ファイルごとのハンクと行（種別・旧行・新行・本文）。
`Cockpit.approvals` → 道具・1行の説明・入力 JSON・届いた時刻・書き換えられるか。
足す予定: ハンクのステージ、コミット列、`gh pr view` の状態、端末、ファイルツリーと保存。
